FileBRSR is an AI-powered SaaS platform that automates BRSR (Business Responsibility and Sustainability Reporting) compliance for Indian listed companies. 4. AI Extraction Pipeline

The core value of FileBRSR is automated extraction of 216 BRSR datapoints from unstructured annual report PDFs. The pipeline uses a triple-extraction strategy for maximum accuracy:

4.1 Extraction Strategy (Triple-Pass)

1
Regex Extraction — Pattern matching for structured data (CIN, revenue, employee counts)
↓
2
Enhanced Extraction — Section-aware parsing with BRSR framework mapping
↓
3
AI Extraction — LLM-powered extraction for complex/narrative datapoints
↓
4
Merge & Validate — Combine results, apply validation engine, score completeness

4.2 AI Provider Fallback Chain

5. Security Architecture

5.1 Multi-Tenant Data Isolation (Row Level Security)

Every user-facing table has PostgreSQL RLS policies ensuring users can only access their own data:

TablePolicyAccess
reportsauth.uid() = user_idSELECT, INSERT, UPDATE, DELETE own rows
brsr_entriesauth.uid() = user_idSELECT, INSERT, UPDATE, DELETE own rows
profilesauth.uid() = idSELECT, UPDATE own profile only
paymentsauth.uid() = user_idSELECT own payments
analytics_eventsauth.uid() = user_idINSERT own events only
extraction_jobsauth.uid() = user_idSELECT own jobs
Service Role: Backend and Worker use Supabase service_role key which bypasses RLS — enabling cross-user operations like admin analytics dashboard and background job processing.

5.2 Admin Access Control

  • is_admin boolean on profiles table gates admin-only features
  • Backend returns HTTP 403 for non-admin users hitting analytics endpoints
  • Frontend hides admin navigation links from non-admin users (defense in depth)

5.3 Infrastructure Security

  • HTTPS everywhere (Let's Encrypt auto-renewal)
  • SSH key-only access (no password auth on EC2)
  • Supabase service_role key stored as env var (never in code)
  • Docker containers with memory limits (prevent DoS via OOM)
  • IMDSv2 enabled on EC2 (token-required metadata)
